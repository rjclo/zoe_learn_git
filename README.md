# Zoe Learns Git 🌱

Welcome! This is a small, friendly practice project to help you learn the basics of Git and GitHub.

There is nothing complicated here — just a few simple files and folders for you to play with.

## What's inside

- `recipes/` — a couple of recipe text files you can edit
- `notes/` — a place to add your own notes
- `LEARN_GIT.md` — a step-by-step guide to follow 👈 **start here!**

## Your goal

Follow the steps in [LEARN_GIT.md](LEARN_GIT.md) to:

1. Clone this project to your computer
2. Create your own branch
3. Make a change (edit a file or add a new one)
4. Save your change with `add` and `commit`
5. `push` it back to GitHub so you can see it online

Have fun! 💛
